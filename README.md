# Инструменты агента для разработки на 1С

Скиллы, MCP-серверы и порядок работы для AI-агентов (Codex, Claude Code, Cursor и других):

| Что | Зачем |
| --- | --- |
| [testing-with-yaxunit](skills/testing-with-yaxunit/SKILL.md) | скилл: подключить YAxUnit, писать юнит- и интеграционные тесты в расширении тестов, запускать и читать jUnit |
| [testing-with-vanessa](skills/testing-with-vanessa/SKILL.md) | скилл: писать сценарии Vanessa Automation по живым формам через MCP Vanessa, запускать пакетно, читать JUnit, статус и Allure |
| [checking-bsl-code](skills/checking-bsl-code/SKILL.md) | скилл: прогнать доработку через BSL Language Server — ошибки, дефекты кода, уязвимости и стандарты 1С, только по изменённым файлам; скрипт сам скачивает закреплённую версию анализатора |
| [mcp/objects](mcp/objects) и [extensions/СервисОбъектов](extensions/СервисОбъектов) | MCP-сервер `onec-objects`: агент ищет типы и объекты, читает схему и объект, создаёт элемент справочника или непроведённый документ в вашей базе. Работает через HTTP-сервис расширения `СервисОбъектов` |
| [mcp/bsl-platform](mcp/bsl-platform/start.mjs) | MCP-сервер `bsl-platform`: справка платформы (синтаксис-помощник) установленной у вас версии — сигнатуры, свойства типов, контекст исполнения. Запускает закреплённую версию [mcp-bsl-platform-context](https://github.com/alkoleft/mcp-bsl-platform-context) |
| [vendor/superpowers](https://github.com/obra/superpowers) | подмодуль: скиллы разработки от спецификации — brainstorming, планы, TDD, субагенты, проверка перед «готово»; ревизия, проверенная со скиллами 1С |
| [docs/workflow.md](docs/workflow.md) | порядок доработки 1С с агентом: что значит каждый шаг Superpowers в 1С, какой уровень теста для чего, что проверить перед «готово» |

Знания собраны на курсе «Разработка на 1С с AI-агентами» (Infostart, 2026): занятия
о MCP-сервере над 1С, YAxUnit и TDD, сценарном тестировании с Vanessa Automation,
прогоны и разбор домашних работ.

Ничего не привязано к машине и к харнессу. Пути, базы, порты и учётная запись — в разделе
«Окружение 1С» в `AGENTS.md` вашего проекта и в записи MCP вашего харнесса; агент
заполняет их вместе с вами.

## Как подключить и обновить

Скажите своему агенту:

> Подключи скиллы и MCP из https://github.com/av-leschinskiy/1c-agent-skills по его инструкции.

Обновить:

> Обнови 1c-agent-skills по его инструкции.

## Инструкция для агента

- **Подключить** — [docs/install.md](docs/install.md).
- **Обновить** уже подключённое — [docs/update.md](docs/update.md).

Коротко: репозиторий подключается клоном git (подмодуль проекта или клон для всех
проектов), скиллы — ссылками в каталог скиллов харнесса, MCP — записью в его конфиг;
обновляется через git. Плагины, маркетплейсы, `skill-installer` и копирование файлов не
использовать.

## Почему git, а не плагин

Плагин и маркетплейс — тот же git-репозиторий плюс манифест, каталог, версия и кэш у
каждого харнесса в своём формате. Для набора скиллов и одного MCP-сервера это лишние
движущиеся части: `SKILL.md` читают все харнессы, запись MCP умеет каждый, а git уже даёт
версии, историю, ревью и обновление.

## Проверено

- Скиллы YAxUnit и Vanessa — на прогонах курса (Linux, платформа 8.5, Codex и Claude Code).
- `checking-bsl-code` — на Linux с Java 21 и со сборкой со встроенной Java; Windows и macOS не проверены.
- MCP-сервер — тестами (`npm test`) и на курсе в составе расширения учебного проекта.
- `bsl-platform` — по протоколу MCP на Linux с Java 17 и справкой платформы 8.5; та же
  версия сервера — на прогонах курса.
- Superpowers v7.0.1 — на прогонах курса вместе со скиллами 1С.
- Расширение `СервисОбъектов` загружено и проверено запросами на платформе 8.5 (Linux);
  на 8.3.24–8.3.27 подтвердите на своей базе и сообщите, если что-то не так.
- Подключение по [docs/install.md](docs/install.md) — агентом Codex в проект с нуля: скиллы,
  MCP и расширение, затем доработка с проверкой через `onec-objects` и BSL LS.
