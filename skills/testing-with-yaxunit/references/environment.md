# Окружение 1С для YAxUnit

Значения машины живут в проекте, а не в скилле: скилл обновляется `git pull`, и правка
внутри него конфликтует с обновлением. Скопировать раздел ниже в `AGENTS.md` проекта
и заполнить вместе с человеком. Если там уже есть раздел «Окружение 1С» от скилла
`testing-with-vanessa`, дописать недостающие строки в него.

```markdown
## Окружение 1С

| Что | Значение |
| --- | --- |
| Платформа и путь к `1cv8` / `1cv8c` | `C:\Program Files\1cv8\8.3.xx.xxxx\bin` |
| База (строка подключения) | файловая `/F"C:\bases\project"` или серверная `/S"srv\base"` |
| Пользователь 1С | `Администратор`; пароль в команды и файлы не вписывать |
| Каталог логов и отчётов (в git не входит) | `logs/` |
| Движок YAxUnit | `vendor/yaxunit/YAxUnit-<версия>.cfe`, sha256 `<...>` |
| Расширение тестов | имя `Тесты`, исходники `src/extensions/Тесты` |
| Конфиги запуска | `tests/yaxunit/юнит.json`, `интеграция.json`, `все.json` |
```

Пароль, если он есть, передаётся из переменной окружения или вводится человеком; в
`AGENTS.md`, конфиги и коммиты он не попадает.

## Команды

Образцы — для Windows и файловой базы. Проверить каждую на своей базе и при расхождении
записать рабочий вариант в `AGENTS.md` проекта рядом с таблицей.

Загрузить движок из `.cfe`:

```bat
"<путь>\1cv8.exe" DESIGNER /F"<база>" /N"<пользователь>" /DisableStartupDialogs ^
  /LoadCfg "vendor\yaxunit\YAxUnit-<версия>.cfe" -Extension YAXUNIT ^
  /UpdateDBCfg -Extension YAXUNIT /Out "<логи>\load-yaxunit.log"
```

Загрузить расширение тестов из файлов XML:

```bat
"<путь>\1cv8.exe" DESIGNER /F"<база>" /N"<пользователь>" /DisableStartupDialogs ^
  /LoadConfigFromFiles "<каталог расширения>" -Extension <Имя> ^
  /UpdateDBCfg -Extension <Имя> /Out "<логи>\load-tests.log"
```

Выгрузить расширение в `.cfe`:

```bat
"<путь>\1cv8.exe" DESIGNER /F"<база>" /N"<пользователь>" /DisableStartupDialogs ^
  /DumpCfg "<каталог>\<Имя>.cfe" -Extension <Имя> /Out "<логи>\dump.log"
```

Снять безопасный режим и защиту от опасных действий — после каждой загрузки, с движка
и с расширения тестов. Утилита `ibcmd` серверной платформы:

```bat
ibcmd config extension update --db-path="<база>" --user="<пользователь>" ^
  --name=YAXUNIT --safe-mode=no --unsafe-action-protection=no
```

Без `ibcmd` — в Предприятии: «Все функции → Стандартные → Управление расширениями
конфигурации».

Запустить тесты:

```bat
"<путь>\1cv8c.exe" ENTERPRISE /F"<база>" /N"<пользователь>" /DisableStartupDialogs ^
  /C"RunUnitTests=<полный путь к конфигу>.json"
```

Клиент закрывается сам при `"closeAfterTests": true`. Результат — файлы `reportPath`
и `exitCode` из конфига.

Linux: те же ключи, путь к платформе вида `/opt/1cv8/x86_64/8.3.xx.xxxx/1cv8`, строки
переносятся `\`, кавычки — одинарные вокруг параметров с пробелами.
